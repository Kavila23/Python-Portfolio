# Python-Portfolio
Here are all the code assignments I have done in AP Computer Science Principals
Adventure - Creates a program that takes users on a mini text adventure. Each choice leads to a new situation using nested if statement… Program must have 4 outcomes
Pokemon - Defines a function named evolve() that checks the value of level. If the level is greater than or equal to a certain threshold (10 for first evolution, 20 for second evolution), it simulates the Pokémon evolving by changing the name of the pokemon and printing an image of the new pokemon. If the pokemon is not ready to evolve, it does nothing. This function is called anytime the level of the pokemon is changed.
Parity - Creates a program that prompts the user for a number and prints whether that number is even or odd.
Disney - The purpose of this program is to match users to a Disney character based off their personality or their appearance
Hogwarts - program that prompts the user for their name and simulates being assigned one of the 4 hogwarts houses
Rock Paper Scissors(RPS) - A simulation of the popular rock paper scissors game where the players plays against the computer
